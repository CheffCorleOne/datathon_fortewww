Что проверяется

        
Только открытые акты РК: Правила № 231 и № 14 НБРК, Требования № 53 АРРФР.

      

      

      
По видео не оцениваются проводки, сверка и документы. Лица на кадрах размываются, распознавание личности не выполняется.

    


    

      

        
API для интеграции

        
Ключ передаётся в заголовке X-API-Key. Обработка асинхронная.

      

      


# 1. Загрузить видео → job_id
curl -X POST /api/v1/analyze \
  -H "X-API-Key: <ключ>" -F "file=@video.mov"

# 2. Получить статус и результат
curl /api/v1/jobs/<job_id> -H "X-API-Key: <ключ>"
