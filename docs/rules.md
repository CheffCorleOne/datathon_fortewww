# Нормативная база и сопоставление с видео

Используются только открытые акты Республики Казахстан (adilet.zan.kz). Во всех случаях сервис ссылается на конкретный пункт. Дословная цитата приводится только там, где текст сверен с опубликованной редакцией. В остальных случаях даётся пересказ с пометкой «изложение».

## Чего сервис не утверждает

- Корректность проводок, сверки и документов по видео не проверяется (раздел 7 ТЗ).
- Формулировки описаний — наблюдение («кассир перелистывает купюры руками»), а не вывод о вине.
- Для пунктов, где связь между нормой и наблюдением является толкованием (телефон, еда, компьютер), в описании стоит «может указывать».
