# Ограничения и известные ошибки

## Принципиальные

- **Только видимое.** Сервис не оценивает проводки, сверку, подписи и документы (раздел 7 ТЗ). Результат — подсказка проверяющему, а не заключение.
- **Один ракурс, низкое разрешение (464×848).** Мелкие предметы (пломба на сумке, ключ в замке сейфа, номинал купюр) на таком кадре не различимы. Нарушения, которые видны только по таким деталям, сервис не утверждает.
- **Типы вне обучающего набора.** Сервис ищет 11 перечисленных типов. Новый тип будет найден, только если совпадёт с одним из сигналов: деньги в руках, уход с места, вход постороннего, вещи на столе.

## Известные слабые места

| Ситуация | Что происходит | Почему |
|---|---|---|
| Кассир сидит спиной к камере и закрывает руки корпусом | Ручной пересчёт может быть пропущен | VLM не видит купюр |
| Голубые купюры в руке | VLM иногда принимает их за телефон | Похожий цвет и форма; поэтому «телефон» засчитывается только при 3 окнах подряд |
| Люди за стеклянной стеной | Отсекаются по относительному размеру; если камера близко к стеклу, могут попасть в подсчёт | Нет карты глубины |
| Предварительный пересчёт руками с последующей машиной | Не считается нарушением, если в течение 6 с есть движение у счётной машины | Так выглядит нормальная практика в «чистых» видео |
| Таймкод при уходе кассира | Берётся последний момент у рабочего места (ноутбук, сейф, машина); если кассир сначала ушёл к сейфу, таймкод на 2–4 с позже, чем в разметке | Разметка отмечает момент вставания, мы — уход из зоны |
| Инкассаторская сумка без проверки пломбы | Не детектируется автоматически | Один пример в датасете, пломба на кадре неразличима |
| Длинные видео (> 2 мин) | Шаг сканирования рук растёт до ~3 с, короткий эпизод может быть пропущен | Лимит 5 минут на видео |
| Занятый GPU | Обработка замедляется в 5–10 раз | Видеокарта делится с другими приложениями |
