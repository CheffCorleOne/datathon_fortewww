# Контроль кассовой дисциплины по видео — Datathon 26 (ForteBank)

Локальный AI-сервис. Принимает видеозапись кассы (.mov) и возвращает вердикт «нарушение / нет нарушения». Для каждого найденного эпизода указывает тип, таймкод, описание, 1–3 кадра-доказательства и ссылку на пункт норматива РК. Все модели работают на машине сервиса, облачные AI-API не используются.

- Веб-интерфейс: `/` — загрузка видео, статус обработки, карточки нарушений с кадрами и нормой, переход к моменту в плеере.
- API для жюри: `POST /api/v1/analyze` (multipart, поле `file`) → `job_id`; `GET /api/v1/jobs/{job_id}` → статус и результат. Обязателен заголовок `X-API-Key`.

## Как это работает

```
.mov ─► декодирование 4 fps ─► RT-DETRv2 (люди, ноутбук, сумки, посуда)
     ─► таймлайн людей в кассе: входы / выходы / касса опустела (без фиксированных зон в пикселях)
     ─► Qwen3-VL-4B (локально, Ollama) отвечает на узкие вопросы по вырезанным фрагментам:
          · где счётная машина, сейф, дверь (один раз на видео)
          · каждые ~1,5 с: что в руках кассира (3 кадра подряд)
          · в момент ухода кассира: заблокирован ли ноутбук, что осталось на столе
          · в момент входа посетителя: лежат ли деньги на столе; кто вошёл
          · в момент прихода кассира: закрыта ли дверь
     ─► временные правила ─► события (тип, таймкод, кадры, норма) ─► JSON по схеме ТЗ
```

Подробнее: [docs/architecture.md](docs/architecture.md), типы нарушений: [docs/violations.md](docs/violations.md), нормативная база: [docs/rules.md](docs/rules.md), ограничения: [docs/limitations.md](docs/limitations.md).

## Запуск (Windows, NVIDIA GPU ≥ 8 ГБ)

```powershell
winget install astral-sh.uv Ollama.Ollama Cloudflare.cloudflared
uv sync                                   # Python 3.12, torch cu128 и зависимости
ollama pull qwen3-vl:4b-instruct          # 3,3 ГБ, один раз (нужен именно *-instruct, без thinking)
.\start.ps1                               # сервис на :8000
.\tunnel.ps1                              # во втором окне: публичный HTTPS-адрес (localhost.run или ngrok)
```

`start.ps1` при первом запуске создаёт `.env` со случайным `API_KEY`. `tunnel.ps1` печатает публичный адрес. Если сеть блокирует порт 7844 (как у нас), Cloudflare quick tunnel не подойдёт, тогда используется localhost.run или ngrok.

Docker (Linux, для переноса во внутренний контур): `docker compose up -d`. Порядок шагов описан в `docker-compose.yml`. После загрузки весов интернет не нужен.

## Пример запроса

```bash
curl -X POST https://<host>/api/v1/analyze -H "X-API-Key: <ключ>" -F "file=@video.mov"
curl https://<host>/api/v1/jobs/<job_id> -H "X-API-Key: <ключ>"
```

Ответ соответствует схеме из раздела 10 ТЗ. Дополнительные поля (`type_code`, `interval_sec`, `confidence`, `rule`, `detected_by`, `debug`) нужны интерфейсу, обязательные поля они не меняют.

## Модели и лицензии (все допускают коммерческое использование)

| Компонент | Модель / библиотека | Лицензия |
|---|---|---|
| Детекция | RT-DETRv2 R50 (`PekingU/rtdetr_v2_r50vd`, transformers) | Apache-2.0 |
| Визуально-языковая модель | Qwen3-VL-4B-Instruct (Q4_K_M, Ollama) | Apache-2.0 |
| Размытие лиц на кадрах | YuNet (OpenCV Zoo) | MIT |
| Трекинг, утилиты | supervision, OpenCV, PyAV, FastAPI | MIT / Apache-2.0 / BSD |

Лица на кадрах-доказательствах размываются; распознавание личности не выполняется.

## Оценка на обучающем наборе

`uv run python tools/eval.py` — прогон всех размеченных видео; `--api <url> --key <ключ>` — то же через HTTP API, как у жюри. `tools/rescore.py <tag> --drop <тип>` пересчитывает метрики с отключёнными типами без повторного инференса.

Последний полный прогон через API (40 уникальных видео, RTX 5060):

| Метрика | Значение |
|---|---|
| Точность вердикта | 65% (26/40) |
| Полнота (найдено видео с нарушением) | 81% (17/21) |
| Ложные тревоги на «чистых» видео | 10/19, из них 8 — «ручной пересчёт» |
| Таймкод: медианная ошибка / в пределах 3 с | 4 с / 7 из 18 |
| Время обработки | 35–50 с на видео 15–25 с; до ~2 мин на видео 70–140 с |

Пороги подобраны на этом же наборе, поэтому на новых видео точность может быть ниже.
